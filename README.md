# Album 90 — The Reckoning Is His
Seven intercession songs. Dust is not a court. Petra is not a clock. Giza is not a forge. The high mountain is not a smith. The voice is not a plague. The Andes are not a furnace. The north is not a site. Christ remains the righteous Judge. Children are His. The Lamb is the market. Naming only — no war manual, no living person appointed Reckoner, Forger, or Warden.

Song line: Dust → Rock → Plateau → Peak → Voice → Range → North.
